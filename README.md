### Welcome to the SMTP Add On GitHub Repository
A reliable WordPress email sending solution for Paid Memberships Pro that integrates with trusted SMTP and API-based providers to improve email deliverability and tracking.

For more information please visit [www.paidmembershipspro.com/add-ons/pmpro-smtp](https://www.paidmembershipspro.com/add-ons/pmpro-smtp)

## Installation ##
For detailed installation steps, visit the [documentation](https://www.paidmembershipspro.com/add-ons/pmpro-smtp) page.

1. Download the current development ZIP file directly: `https://github.com/strangerstudios/pmpro-smtp/archive/dev.zip`

**Please ensure that once installing this version of the plugin to remove `-dev` from the plugin's folder name.**

## Contributing to SMTP Add On ##
We encourage and welcome any contribution to SMTP Add On. Please read the [guidelines for contributing](https://github.com/strangerstudios/paid-memberships-pro/blob/dev/.github/CONTRIBUTING.md) to this repository.

There are various **ways to the help development** of SMTP Add On:

1. Report [bugs/issues](https://github.com/strangerstudios/pmpro-smtp/issues/new) on GitHub.
2. Work on any issues by submitting a Pull Request.

Here are some ways for **non-developers to contribute** to SMTP Add On:

1. Translate SMTP Add On into your own [language](https://www.paidmembershipspro.com/paid-memberships-pro-in-your-language/).
2. [Purchase a paid membership](https://www.paidmembershipspro.com/pricing) to help fund ongoing development and bug fixes.
3. Leave an honest review for [Paid Memberships Pro - SMTP Add On](https://www.paidmembershipspro.com/submit-testimonial/).
